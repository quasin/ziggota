# Ziggota — Agent Instructions

Ziggota ("You're got a Release") is a static, framework-free web app: a downloader for
public files on the Autonomi network. It runs the official
`@withautonomi/ant-browser-sdk` (WebAssembly client + WebRTC direct protocol) inside the
browser, so there is no backend, no daemon and no wallet code. Vite only serves and
bundles the assets.

## Dev environment

    node --version                     # needs >= 20.19; the SDK is ESM-only
    npm install
    npm run dev                        # http://localhost:5173
    npm run build                      # emits dist/: JS, CSS, .wasm, upload worker
    npm run preview                    # serve dist/ for a smoke test
    npm run build:single               # inlines everything into ./ziggota.html

No tests, linter or formatter are configured. Verify changes by loading the page and
running a real download (see "Smoke test").

## Layout

    index.html            markup only; all behaviour lives in src/main.js
    src/main.js           client lifecycle, queue, download orchestration, DOM updates
    src/style.css         dark theme, CSS custom properties on :root
    vite.config.js        optimizeDeps.exclude for the SDK (required — see Pitfalls)
    dist/                 build output, generated; never edit by hand

## Conventions

- Vanilla ES modules, no framework, no TypeScript.
- Build DOM with `createElement` + `textContent`. Never pass network-supplied strings
  (`entry.path`, progress `message`) through `innerHTML`.
- Items move through `queued | running | done | error | cancelled`; `paint(item)` is the
  only function that renders an item's state.
- Report failures through `describeError()`, which prints `AutonomiError.code` rather
  than a stack trace; keep user-facing error text code-first.
- File names go through `safeSegment()` / `safePath()`; manifest paths are recreated as
  nested directories instead of being flattened.
- SDK-facing fields stay camelCase (`contentType`, `knownSize`); snake_case belongs to
  the Rust wire only.
- Commit messages are plain imperative sentences ("Update README.md"); no Conventional
  Commits prefixes, single long-lived branch `main`.
- Do not bump versions as a side effect of a change; a feature landing is not a release.

## Pitfalls

- The SDK is pinned exactly (`0.1.5`) because its bundled WASM speaks a specific node
  protocol version (browser protocol v5). Upgrading is its own change, tested against
  the live network.
- Keep the SDK in `optimizeDeps.exclude`. It resolves `ant_core_bg.wasm` and
  `upload-worker.js` via `new URL(..., import.meta.url)`; dep pre-bundling breaks both
  and the page fails during `connect()`.
- `streamAndSave()` / `downloadAndSave()` open a file picker, which consumes the click's
  user activation. Never `await` connect/openFile before calling them — `startAll()`
  requests `showDirectoryPicker()` first for that reason.
- Streaming reads skip a manifest entry's `sha256` check (buffered `download()` does it),
  and `entry.size` is a creator hint, not a guarantee.
- `download()` buffers the entire file and rejects above `maxMemoryBytes` (1 GB default).
  It is only the fallback for browsers without the File System Access API.
- Secure context needed: HTTPS or localhost, `.wasm` served as `application/wasm`, and
  `dist/assets/*.wasm` plus `*-worker-*.js` deployed with the JS.
- `dist/` and `node_modules/` are gitignored; don't stage them.
- `ziggota.html` is generated by `scripts/build-single.mjs` (run `npm run build:single`
  after `npm run build`). Never hand-edit it: it is 7.7 MB of inlined bundle plus the
  base64 WASM, and it deliberately replaces the SDK upload worker with a throwing stub.
  Test it from an HTTP server, not `file://`.

## Smoke test

Paste this public mainnet address (the 138,931-byte JPEG the SDK docs use), press
"Add to queue", then "Download all…" or "Save…":

    711c7e20006ff3e0ac6c1f3063286a0c1a3e4c409642e8c526173fa60bb7078a

Expect `mainnet · chain 42161` in the header and "Saved 136 KB" in the row. Manifest
links can be produced offline from the SDK (`createManifest()`); raw addresses carry no
filename or MIME type.
